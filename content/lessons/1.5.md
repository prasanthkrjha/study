# Stack

A stack (LIFO — last in, first out) is the right structure whenever a problem involves **nesting** or "the most recent unresolved thing matters most."

## Parentheses / bracket matching

The canonical use case: push opening brackets, and when you see a closing bracket, check it matches the top of the stack.

```js
function isValid(s) {
  const pairs = { ")": "(", "]": "[", "}": "{" };
  const stack = [];
  for (const ch of s) {
    if (!pairs[ch]) { stack.push(ch); continue; }
    if (stack.pop() !== pairs[ch]) return false;
  }
  return stack.length === 0;
}
```

## Monotonic stack

A monotonic stack keeps its elements in strictly increasing or decreasing order by popping anything that violates the order before pushing the new element. This is the pattern behind "next greater element," "daily temperatures," and "largest rectangle in histogram."

```js
function nextGreaterElement(nums) {
  const result = new Array(nums.length).fill(-1);
  const stack = []; // stores indices, values are decreasing top-to-bottom is wrong direction — see below
  for (let i = 0; i < nums.length; i++) {
    while (stack.length && nums[stack[stack.length - 1]] < nums[i]) {
      const idx = stack.pop();
      result[idx] = nums[i];
    }
    stack.push(i);
  }
  return result;
}
```

Walk through it: the stack holds indices whose "next greater element" hasn't been found yet. Every time a bigger value shows up, it resolves everyone smaller than it still sitting on the stack — each index is pushed once and popped once, so this is O(n) despite the nested-looking `while`.

## Why "next greater element" specifically matters

It's the template for a whole family: next smaller element, previous greater element, stock span, and histogram-area problems are all the same monotonic-stack skeleton with the comparison direction flipped.

## Recognizing the pattern

- "Valid parentheses / matching pairs" → plain stack.
- "Next/previous greater or smaller element" → monotonic stack.
- You're processing a sequence and need to look back at "the most recent unresolved item" → stack, not a hashmap or a second loop.
