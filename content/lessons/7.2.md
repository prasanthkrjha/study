# Neural Networks & Deep Learning

Neural networks are the computational foundation behind every large language model, image recognition system, and recommendation engine that powers modern AI products. Understanding how they work — not just how to import them — is what lets you make informed decisions about architecture, debug training failures, and speak credibly about deep learning in interviews without sounding like you are reciting a textbook definition.

This unit covers the core concepts from the single perceptron through the architecture patterns (CNNs, RNNs) that underpin the specialized models in Module 8. The focus is conceptual fluency backed by concrete code: understanding what backpropagation is actually doing, why activation functions matter, and why a CNN works for images but an RNN (or Transformer) works for sequences.

For the AI engineer path, deep learning knowledge has a specific practical application: it explains why LLMs behave the way they do, why attention is the key mechanism in Transformers, and why fine-tuning can change model behavior while RAG cannot. These connections are developed in Unit 8.1.

## Theory & Fundamentals

**The perceptron and linear separability**: A single perceptron computes a weighted sum of its inputs, adds a bias, passes the result through an activation function, and produces one output. It is a linear classifier — the decision boundary it can learn is a straight line (or hyperplane in higher dimensions). XOR is the canonical example of a problem a single perceptron cannot solve, because no single line separates XOR's true inputs from its false inputs. Stacking perceptrons into layers (multi-layer perceptron / MLP) solves this: the hidden layers learn non-linear representations of the input.

**Forward pass**: The input propagates layer by layer through the network. At each layer, every neuron computes `output = activation(W · input + b)` where W is the weight matrix, b is the bias vector, and `activation` is a non-linear function. The non-linearity is essential — without it, a stack of linear layers is mathematically equivalent to a single linear layer (the composition of linear functions is linear), which cannot learn anything a simple linear model cannot.

**Loss functions**: The loss function measures how wrong the model's predictions are on the training examples. For binary classification, binary cross-entropy; for multiclass, categorical cross-entropy; for regression, mean squared error. The entire training procedure is gradient descent on this loss.

**Backpropagation**: Backpropagation is the algorithm for computing the gradient of the loss with respect to every weight in the network, using the chain rule of calculus. The gradient tells you how much each weight contributed to the error and in which direction to change it to reduce the error. Gradient descent then takes a small step in the negative gradient direction: `w = w - learning_rate * gradient`. Modern frameworks (PyTorch, TensorFlow) compute all gradients automatically (autograd) — you define the forward pass and the loss; the framework handles the rest.

**Activation functions**: ReLU (max(0, x)) is the default for hidden layers — computationally cheap, avoids the vanishing gradient problem that plagued sigmoid/tanh in deep networks. Sigmoid (output 0-1) is used for binary output neurons. Softmax (normalizes logits into a probability distribution summing to 1) is used for multiclass output layers. GELU (used in Transformers/LLMs) is a smooth approximation to ReLU.

**Regularization in neural networks**: L2 weight decay (penalizes large weights), dropout (randomly zeroes a fraction of neuron activations during training, forcing redundant representations), and batch normalization (normalizes activations within a mini-batch, stabilizing training and acting as a mild regularizer) are the primary tools for reducing overfitting in neural networks.

## Core Concepts / Techniques

**Building a simple MLP with PyTorch**:
```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim, dropout_rate=0.3):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.BatchNorm1d(hidden_dim),
            nn.ReLU(),
            nn.Dropout(dropout_rate),
            nn.Linear(hidden_dim, hidden_dim // 2),
            nn.ReLU(),
            nn.Linear(hidden_dim // 2, output_dim),
        )

    def forward(self, x):
        return self.net(x)   # binary classification: apply sigmoid externally
```

**Training loop**:
```python
model = MLP(input_dim=20, hidden_dim=128, output_dim=1)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-4)
criterion = nn.BCEWithLogitsLoss()  # sigmoid + BCE, numerically stable

for epoch in range(50):
    model.train()
    optimizer.zero_grad()
    logits = model(X_train_tensor).squeeze()
    loss = criterion(logits, y_train_tensor.float())
    loss.backward()          # compute all gradients via backprop
    optimizer.step()         # update weights

    model.eval()
    with torch.no_grad():
        val_logits = model(X_val_tensor).squeeze()
        val_loss = criterion(val_logits, y_val_tensor.float())
    print(f"Epoch {epoch+1}: train_loss={loss.item():.4f}  val_loss={val_loss.item():.4f}")
```

**CNN building blocks** (for image/sequence with local patterns):
```python
class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        # Feature extractor: convolutional layers
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, kernel_size=3, padding=1),  # 28x28 -> 28x28
            nn.ReLU(),
            nn.MaxPool2d(2),                              # 28x28 -> 14x14
            nn.Conv2d(32, 64, kernel_size=3, padding=1), # 14x14 -> 14x14
            nn.ReLU(),
            nn.MaxPool2d(2),                              # 14x14 -> 7x7
        )
        # Classifier: fully connected layers
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 7 * 7, 256),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(256, num_classes),
        )

    def forward(self, x):
        return self.classifier(self.features(x))
```

## Code Examples

```python
"""
Complete neural network training pipeline with early stopping,
learning rate scheduling, and evaluation.
"""
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# ─── 1. Data Preparation ─────────────────────────────────────────────────────
X, y = make_classification(
    n_samples=5000, n_features=20, n_informative=10,
    n_redundant=5, random_state=42
)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)
X_train, X_val, y_train, y_val = train_test_split(
    X_train, y_train, test_size=0.2, stratify=y_train, random_state=42
)

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_val   = scaler.transform(X_val)
X_test  = scaler.transform(X_test)

def to_tensors(X, y):
    return (torch.tensor(X, dtype=torch.float32),
            torch.tensor(y, dtype=torch.float32))

X_tr, y_tr = to_tensors(X_train, y_train)
X_vl, y_vl = to_tensors(X_val,   y_val)
X_te, y_te = to_tensors(X_test,  y_test)

train_loader = DataLoader(TensorDataset(X_tr, y_tr), batch_size=64, shuffle=True)

# ─── 2. Model ─────────────────────────────────────────────────────────────────
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(20, 128), nn.BatchNorm1d(128), nn.ReLU(), nn.Dropout(0.3),
            nn.Linear(128, 64), nn.ReLU(), nn.Dropout(0.2),
            nn.Linear(64, 1),
        )
    def forward(self, x):
        return self.net(x).squeeze()

model = MLP()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-4)
scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(
    optimizer, patience=5, factor=0.5, verbose=True
)
criterion = nn.BCEWithLogitsLoss()

# ─── 3. Training with Early Stopping ─────────────────────────────────────────
best_val_loss = float("inf")
patience_counter = 0
PATIENCE = 10
history = {"train": [], "val": []}

for epoch in range(200):
    # Train
    model.train()
    train_losses = []
    for X_b, y_b in train_loader:
        optimizer.zero_grad()
        loss = criterion(model(X_b), y_b)
        loss.backward()
        nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)  # gradient clipping
        optimizer.step()
        train_losses.append(loss.item())

    # Validate
    model.eval()
    with torch.no_grad():
        val_loss = criterion(model(X_vl), y_vl).item()
        train_loss = np.mean(train_losses)

    history["train"].append(train_loss)
    history["val"].append(val_loss)
    scheduler.step(val_loss)

    # Early stopping
    if val_loss < best_val_loss - 1e-4:
        best_val_loss = val_loss
        torch.save(model.state_dict(), "best_model.pt")
        patience_counter = 0
    else:
        patience_counter += 1
        if patience_counter >= PATIENCE:
            print(f"Early stopping at epoch {epoch+1}")
            break

# ─── 4. Load Best Model & Evaluate ───────────────────────────────────────────
model.load_state_dict(torch.load("best_model.pt"))
model.eval()
with torch.no_grad():
    probs = torch.sigmoid(model(X_te)).numpy()
    preds = (probs >= 0.5).astype(int)

from sklearn.metrics import classification_report, roc_auc_score
print("ROC-AUC:", roc_auc_score(y_test, probs))
print(classification_report(y_test, preds))

# ─── 5. Learning Curves ───────────────────────────────────────────────────────
plt.figure(figsize=(8, 4))
plt.plot(history["train"], label="Train Loss")
plt.plot(history["val"],   label="Val Loss")
plt.xlabel("Epoch")
plt.ylabel("BCE Loss")
plt.title("Training and Validation Loss")
plt.legend()
plt.tight_layout()
plt.savefig("learning_curves.png", dpi=150)
plt.show()
```

## Best Practices

- **Start with a small model and scale up.** Begin with 1-2 hidden layers. Add capacity only when the model clearly underfits — a model with unnecessary capacity overfits and requires more data and regularization to fix.
- **Use `BCEWithLogitsLoss` instead of `BCELoss` + sigmoid.** The combined form is numerically more stable (avoids floating-point overflow when logits are very large or small).
- **Always normalize inputs.** Neural networks are sensitive to input scale — unnormalized inputs cause training to be slow or unstable. Apply `StandardScaler` (or equivalent) before training and use the same transformation at inference.
- **Monitor both training and validation loss.** The gap between them is your overfitting signal. A large gap means the model is memorizing; a large value on both means underfitting.
- **Use early stopping with a patience parameter.** Let the model train until validation loss stops improving, then roll back to the best checkpoint. This is more principled than setting a fixed epoch count.
- **Apply gradient clipping** (`nn.utils.clip_grad_norm_`) to prevent exploding gradients, especially in RNNs and when training with a high learning rate.
- **Save checkpoints during training.** Hardware interruptions, CUDA out-of-memory errors, and unexpected kills are real. Saving the best checkpoint means you can recover without retraining from scratch.

## Common Interview Questions

**Q: What is backpropagation?**
A: Backpropagation is the algorithm for computing the gradient of the loss function with respect to every weight in the network, using the chain rule of calculus. Starting from the output loss and working backward through the layers, it attributes how much each weight contributed to the error. Gradient descent then uses these gradients to update weights in the direction that reduces the loss.

**Q: Why are activation functions necessary in a neural network?**
A: Without non-linear activation functions, a stack of linear layers is mathematically equivalent to a single linear layer (the composition of linear functions is linear). Non-linearities allow the network to learn complex, non-linear mappings between inputs and outputs — representing curves, boundaries, and interactions that a linear model cannot capture.

**Q: What is vanishing gradient and how does ReLU help?**
A: Vanishing gradient occurs when gradients shrink exponentially as they propagate backward through deep networks (common with sigmoid/tanh, whose derivatives are small for large or small inputs). ReLU's derivative is either 0 (for negative inputs) or 1 (for positive inputs) — the gradient passes through unchanged for positive activations, avoiding the exponential shrinkage and enabling training of much deeper networks.

**Q: What is dropout and what problem does it solve?**
A: Dropout randomly sets a fraction of neuron outputs to zero during each training step, forcing the network to learn redundant representations (no single neuron can be relied on exclusively). This is a powerful regularization technique that reduces co-adaptation of neurons and significantly reduces overfitting in deep networks. At inference time, dropout is disabled and weights are scaled to compensate.

**Q: What is batch normalization and why is it useful?**
A: Batch normalization normalizes the activations within a mini-batch to zero mean and unit variance, then applies learnable scale and shift parameters. Benefits: stabilizes training (reduces sensitivity to learning rate), accelerates convergence, acts as mild regularization, and reduces the need for careful weight initialization. It is applied after the linear transform and before the activation function.

**Q: What is the difference between a CNN and a fully connected network?**
A: A CNN uses convolutional layers that learn local spatial patterns by sliding a small filter (kernel) across the input. Weights are shared across all positions (parameter efficiency). Fully connected layers treat every input element independently — no spatial structure is assumed. CNNs are appropriate when input has spatial or sequential local structure (images, audio spectrograms) where nearby elements are more related than distant ones.

**Q: What is the difference between an RNN and a Transformer for sequence modeling?**
A: RNNs process sequences one step at a time, maintaining a hidden state that accumulates information from previous steps — they struggle with long-range dependencies due to vanishing gradients and cannot be parallelized during training. Transformers process the entire sequence in parallel using self-attention, which directly computes relationships between any two positions regardless of distance — this allows better long-range dependency capture and efficient parallel training but requires O(n²) memory for sequence length n.

**Q: What is learning rate and why does it matter?**
A: The learning rate controls how large a step gradient descent takes toward the minimum of the loss function. Too large: oscillates around the minimum, never converges, or diverges. Too small: takes forever to converge or gets stuck in a local minimum. Typical starting values: 1e-3 for Adam, 1e-1 for SGD. Learning rate schedulers (ReduceLROnPlateau, cosine annealing) reduce the rate during training for better final convergence.

## Practice Exercises

1. **XOR problem**: Manually build a two-layer neural network (no frameworks) using only NumPy — implement the forward pass and backpropagation by hand. Train it to solve XOR. This forces you to understand the exact math without hiding behind a framework.

3. **Overfitting experiment**: Take the housing prices regression dataset and deliberately overfit a large MLP (many layers, many neurons, no regularization). Observe the training vs. validation RMSE gap. Then add dropout and L2 weight decay, and track how the gap changes.

Compare test accuracy to a model trained from scratch on the same data.

## Key Takeaways

- A neural network is a composition of linear transforms and non-linear activation functions — the non-linearities are what make it expressive beyond linear models.
- Backpropagation applies the chain rule to compute gradients of the loss with respect to every weight, enabling gradient descent to train arbitrarily deep networks.
- ReLU is the default activation function for hidden layers — computationally cheap, avoids vanishing gradients, and empirically works well across a wide range of architectures.
- Dropout and batch normalization are standard regularization tools for deep networks; early stopping prevents overfitting without needing to specify the number of epochs in advance.
- CNNs leverage spatial structure through weight sharing (convolutional kernels) — appropriate for any input with local structural patterns (images, time-series).
- RNNs process sequences step-by-step with hidden state; Transformers process sequences in parallel with self-attention — this architectural difference is what makes Transformers dominant for LLMs.
- The learning rate is the most sensitive hyperparameter — use Adam with 1e-3 as the starting point, then schedule it downward as training progresses.
- Normalizing inputs is not optional for neural networks — unnormalized features of vastly different scales cause unstable training.
