# Advanced Graphs

This unit covers the four "named algorithms" that show up once plain BFS/DFS isn't enough — when edges have weights, or you need global structure across the whole graph rather than just reachability.

## Union-Find (Disjoint Set Union)

Union-Find answers "are these two nodes in the same group?" and "merge these two groups" in **almost O(1)** time each (technically O(α(n)), the inverse Ackermann function — effectively constant for any input size you'll ever see):

```js
class UnionFind {
  constructor(n) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.rank = new Array(n).fill(0);
  }
  find(x) {
    if (this.parent[x] !== x) this.parent[x] = this.find(this.parent[x]); // path compression
    return this.parent[x];
  }
  union(a, b) {
    const rootA = this.find(a), rootB = this.find(b);
    if (rootA === rootB) return false; // already connected — this edge would form a cycle
    if (this.rank[rootA] < this.rank[rootB]) [rootA, rootB] = [rootB, rootA];
    this.parent[rootB] = rootA;
    if (this.rank[rootA] === this.rank[rootB]) this.rank[rootA]++;
    return true;
  }
}
```

Used for: detecting cycles while building a graph edge-by-edge, counting connected components, and as a building block inside Kruskal's algorithm below.

## Dijkstra's shortest path

Finds shortest paths from one source to all nodes in a graph with **non-negative** edge weights, using a min-heap to always expand the currently-closest unvisited node next:

```js
function dijkstra(graph, source) {
  const dist = new Map([[source, 0]]);
  const heap = [[0, source]]; // [distance, node] — conceptually a min-heap by distance
  const visited = new Set();
  while (heap.length) {
    heap.sort((a, b) => a[0] - b[0]); // stand-in for a real priority queue
    const [d, node] = heap.shift();
    if (visited.has(node)) continue;
    visited.add(node);
    for (const [neighbor, weight] of graph[node] ?? []) {
      const newDist = d + weight;
      if (newDist < (dist.get(neighbor) ?? Infinity)) {
        dist.set(neighbor, newDist);
        heap.push([newDist, neighbor]);
      }
    }
  }
  return dist;
}
```

This is BFS's weighted cousin: BFS assumes every edge costs 1, so a plain queue works; Dijkstra needs a priority queue because the "closest" unvisited node isn't necessarily the one discovered earliest.

## Minimum Spanning Tree — Prim's and Kruskal's

An MST connects all nodes with the minimum possible total edge weight, no cycles. **Kruskal's** sorts all edges by weight and greedily adds each one unless it would form a cycle (checked via Union-Find). **Prim's** grows a single tree outward, always adding the cheapest edge that connects a new node (a min-heap, similar to Dijkstra's shape). Kruskal's is usually easier to reason about and implement in an interview.

## Topological sort

Only defined for **directed acyclic graphs (DAGs)** — orders nodes so every edge points from earlier to later in the ordering. Used for task scheduling with dependencies ("course prerequisites"). Kahn's algorithm: repeatedly remove nodes with in-degree 0 (no remaining dependencies), appending them to the order and decrementing their neighbors' in-degrees.

## Recognizing the pattern

Weighted "shortest path" → Dijkstra. "Connect everything as cheaply as possible" → MST (Kruskal's/Prim's). "Order these tasks given dependencies" → topological sort. "Will adding this edge create a cycle?" or "how many groups after all these merges?" → Union-Find.
