# NumPy & Pandas

If Python core language is about syntax, NumPy and Pandas are about the actual daily tools of data work — everything downstream (scikit-learn, embeddings, RAG data prep) assumes fluency here.

## NumPy: arrays and vectorized operations

A NumPy array is a fixed-type, contiguous block of numbers — much faster than a Python list for numeric work, because operations run in optimized C code instead of a Python loop:

```python
import numpy as np

a = np.array([1, 2, 3, 4])
b = np.array([10, 20, 30, 40])

c = a + b            # [11, 22, 33, 44] — element-wise, no explicit loop
d = a * 2             # [2, 4, 6, 8]
mean = a.mean()        # 2.5
mask = a[a > 2]        # [3, 4] — boolean filtering

matrix = np.array([[1, 2], [3, 4]])
matrix.shape           # (2, 2)
matrix.T                # transpose
```

The core idea to internalize: **vectorization**. `a + b` operates on the whole array at once instead of writing `for i in range(len(a)): c[i] = a[i] + b[i]`. This isn't just cleaner syntax — it's dramatically faster, since NumPy pushes the loop down into compiled code. Whenever you catch yourself writing an explicit Python loop over a NumPy array, ask whether a vectorized operation replaces it.

## Pandas: DataFrames

A DataFrame is a table — rows and named columns, like a spreadsheet or a SQL result set, built on top of NumPy arrays internally:

```python
import pandas as pd

df = pd.read_csv("orders.csv")
df.head()                          # first 5 rows
df.info()                          # column types, null counts
df["total"].sum()                  # aggregate one column
df[df["status"] == "completed"]    # filter rows, like SQL's WHERE
```

## Cleaning

```python
df = df.dropna(subset=["email"])            # drop rows missing a required field
df["price"] = df["price"].fillna(0)          # fill missing values
df = df.drop_duplicates(subset=["order_id"])
df["email"] = df["email"].str.lower().str.strip()
```

Real datasets are messy by default — missing values, duplicate rows, inconsistent casing. Cleaning is usually the majority of the actual work in any data task, not the analysis itself.

## Filtering and grouping

```python
completed = df[df["status"] == "completed"]

by_user = df.groupby("user_id")["total"].sum().reset_index()
by_user_and_status = df.groupby(["user_id", "status"]).size()
```

`groupby` is Pandas' direct equivalent of SQL's `GROUP BY` — split into groups by a key, apply an aggregate, combine the results.

## Pivot tables

```python
pivot = df.pivot_table(
    values="total", index="user_id", columns="status", aggfunc="sum", fill_value=0
)
```

Reshapes long-format data (one row per transaction) into wide-format (one row per user, one column per status) — useful for summaries and for feeding cleaned, structured data into a model in Module 7.
