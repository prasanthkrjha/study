# Sliding Window

Sliding window is two-pointers' sibling, specialized for **contiguous subarray/substring** problems — "longest," "shortest," or "count of" a substring/subarray satisfying some condition.

## Fixed-size window

When the window size `k` is given directly, slide it across the array, adding the new element and removing the old one instead of recomputing from scratch:

```js
function maxSumSubarray(nums, k) {
  let windowSum = 0;
  for (let i = 0; i < k; i++) windowSum += nums[i];
  let best = windowSum;
  for (let i = k; i < nums.length; i++) {
    windowSum += nums[i] - nums[i - k]; // add new, drop oldest
    best = Math.max(best, windowSum);
  }
  return best;
}
```

This turns an O(n·k) brute force into O(n).

## Variable-size window

When the window size isn't fixed — "smallest subarray with sum ≥ target," "longest substring without repeating characters" — grow the right edge until the condition breaks (or is satisfied), then shrink the left edge to recover validity:

```js
function longestUniqueSubstring(s) {
  const seen = new Set();
  let left = 0, best = 0;
  for (let right = 0; right < s.length; right++) {
    while (seen.has(s[right])) {
      seen.delete(s[left]);
      left++;
    }
    seen.add(s[right]);
    best = Math.max(best, right - left + 1);
  }
  return best;
}
```

Notice `left` only ever moves forward — it never resets. That's what keeps this O(n) instead of O(n²): each character is added to the set once and removed once, across the whole run.

## Substring problems specifically

Problems like "minimum window substring" combine sliding window with a frequency map: expand until the window contains all required characters, then contract while it still does, tracking the smallest valid window seen.

## Recognizing the pattern

Ask: "Am I looking at every contiguous chunk of the array/string, and does a brute force re-scan each chunk from scratch?" If yes, sliding window almost certainly turns it linear. The giveaway phrases in problem statements are "subarray," "substring," "contiguous," and "window."
