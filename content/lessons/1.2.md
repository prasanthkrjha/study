# Arrays & Hashing

This is the highest-frequency pattern family in interviews — a huge fraction of "easy" and "medium" problems reduce to "can you avoid a nested loop by remembering what you've already seen." That's what hashmaps and hashsets buy you.

## The core trick: trade memory for time

A brute-force approach to "have I seen this before?" or "does a complement exist?" is usually a nested loop — O(n²). A hashmap turns "have I seen X?" into an O(1) lookup, collapsing the whole thing to O(n) at the cost of O(n) extra space. Recognizing this trade is the single biggest unlock in this unit.

## Two-Sum: the canonical example

```js
function twoSum(nums, target) {
  const seen = new Map(); // value -> index
  for (let i = 0; i < nums.length; i++) {
    const complement = target - nums[i];
    if (seen.has(complement)) return [seen.get(complement), i];
    seen.set(nums[i], i);
  }
  return [];
}
```

Notice the map is built **as you iterate**, not upfront — this lets you find a pair in a single pass instead of two.

## Frequency counting

Any problem involving "most common," "anagram," or "count occurrences" wants a frequency map:

```js
function isAnagram(a, b) {
  if (a.length !== b.length) return false;
  const freq = {};
  for (const ch of a) freq[ch] = (freq[ch] ?? 0) + 1;
  for (const ch of b) {
    if (!freq[ch]) return false;
    freq[ch]--;
  }
  return true;
}
```

## Prefix sums

When a problem asks about a **range** ("sum of subarray from i to j", "does a subarray sum to k?"), precompute running totals so any range query becomes O(1):

```js
function subarraySumEqualsK(nums, k) {
  const prefixCount = new Map([[0, 1]]);
  let sum = 0, count = 0;
  for (const n of nums) {
    sum += n;
    count += prefixCount.get(sum - k) ?? 0;
    prefixCount.set(sum, (prefixCount.get(sum) ?? 0) + 1);
  }
  return count;
}
```

The trick: if `sum - k` has appeared before as a prefix sum, everything between that point and now sums to exactly `k`.

## Grouping / categorization

Group items by a computed key (sorted string for anagram groups, first letter, remainder mod k) using a hashmap of arrays:

```js
function groupAnagrams(strs) {
  const groups = new Map();
  for (const s of strs) {
    const key = [...s].sort().join("");
    if (!groups.has(key)) groups.set(key, []);
    groups.get(key).push(s);
  }
  return [...groups.values()];
}
```

## Recognizing the pattern in the wild

Ask yourself: "Do I need to remember something about elements I've already visited?" If yes — a count, a previous value, an index, a running sum — reach for a hashmap before reaching for a nested loop. This one question resolves most of Weeks 1–2 of your DSA schedule.
