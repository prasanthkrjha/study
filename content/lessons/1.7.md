# Linked List

Linked lists are where "draw it on paper first" pays off most — almost every bug in this unit comes from losing track of a pointer, not from misunderstanding the algorithm.

## Reversal

The core skill: walk the list once, re-pointing each node's `next` to the previous node instead of the next one.

```js
function reverseList(head) {
  let prev = null, curr = head;
  while (curr) {
    const next = curr.next; // save before overwriting
    curr.next = prev;
    prev = curr;
    curr = next;
  }
  return prev; // new head
}
```

## Fast-slow pointers (Floyd's cycle detection)

Move one pointer one step at a time, another two steps at a time. If there's a cycle, the fast pointer eventually laps the slow one and they meet — this is the standard way to detect a cycle in O(n) time and O(1) space, without a visited-set.

```js
function hasCycle(head) {
  let slow = head, fast = head;
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }
  return false;
}
```

The same technique finds the **middle of a linked list** in one pass: when `fast` reaches the end, `slow` is at the midpoint.

## Merge operations

Merging two sorted lists is a direct analog of the merge step in merge sort — compare heads, attach the smaller, advance that list:

```js
function mergeTwoLists(a, b) {
  const dummy = { next: null };
  let tail = dummy;
  while (a && b) {
    if (a.val <= b.val) { tail.next = a; a = a.next; }
    else { tail.next = b; b = b.next; }
    tail = tail.next;
  }
  tail.next = a ?? b;
  return dummy.next;
}
```

## The dummy-node technique

Whenever the **head itself might change** (removing the first node, merging lists, partitioning), create a placeholder `dummy` node pointing at the real head. Do all your work relative to `dummy`, and return `dummy.next` at the end. This removes an entire category of "special case for the first node" bugs.

## Recognizing the pattern

- Reversal, palindrome-checking, and "reorder list" problems → reversal + fast/slow.
- Cycle detection, middle-of-list, "nth node from the end" → fast/slow pointers.
- Any operation that might delete/replace the head node → dummy node, no exceptions.
